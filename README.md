# Python ile Çevresel Modelleme: Tahtalı Barajı Su Bütçesi

İYTE Çevre Topluluğu için hazırlanmış 3 günlük, açık kaynak bir Python eğitimi.
İzmir'in en büyük içme suyu kaynağı olan Tahtalı Barajı'nın aylık su bütçesi
üzerinden **veri hazırlama → model kurulumu → görselleştirme** adımlarını öğretir.
